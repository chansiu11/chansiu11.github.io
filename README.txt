# Mobile FPS Online

## 1. 준비
PC에 Node.js를 설치합니다.

## 2. 서버 폴더에서 실행
```bash
npm install ws
node server.js
```

## 3. 모바일에서 접속
PC와 휴대폰을 같은 Wi-Fi에 연결합니다.

PC의 내부 IP가 예를 들어 `192.168.0.10`이면,
휴대폰 브라우저에서:

`http://192.168.0.10:8080`

으로 접속합니다.

주의: 현재 server.js는 8080 포트의 WebSocket 서버이고 index.html은 같은 호스트의 8080 포트로 WebSocket을 연결합니다. 실제 웹 배포에서는 HTTPS/WSS와 정적 파일 서버를 함께 구성하는 것을 권장합니다.

## 조작
- 왼쪽: 이동
- 화면 오른쪽 드래그: 시점 회전
- FIRE: 발사

현재 버전은 온라인 멀티플레이의 기본 골격입니다. 다음 단계에서 맵, 총기, 리스폰, 팀전, 점수판, 사운드 등을 추가할 수 있습니다.
